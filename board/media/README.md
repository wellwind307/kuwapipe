# 实测素材目录

> **已有一部分实测输出**：板端 DDR 抓帧（处理 / 直通成对对照，共 4 张）放在
> [`../../data/`](../../data/README.md) 第 2 节（`proc_outdoor.png` / `raw_outdoor.png` /
> `proc_desk.png` / `raw_desk.png`），那是 `cam.readframe()` 直接存下的画面，可直接作为
> 指南 A4「实测输出」的板端证据。

本目录放**实物 / 现场素材**（命名见 [`../README.md`](../README.md) 第 4 节）：

- `proc_*.jpg` / `proc_*.mp4`：处理模式下的屏幕实拍照/录屏
- `raw_*.jpg`  / `raw_*.mp4` ：直通模式下的同机位对照
- `switch_*.mp4`：按 PL_KEY0 切换、LED2 亮灭与画面切换同框

要求：同机位、同场景、画面里有 LED2 状态，文件不要超过 20 MB。
